# novacarrentals

Nova Car Rentals — customer marketing site, admin dashboard, and backend API for car hire across East Africa.

## Structure

- `src/` — customer website (Vite + React)
- `frontend/` — admin dashboard
- `backend/` — FastAPI / Python API

## Setup

Copy `.env.example` / `.env.production.example` as needed, then:

```bash
npm install
npm run dev
```
